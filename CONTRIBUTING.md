# Contributing Guidelines

## 1. Create a Branch

Create a separate branch for each feature or bug fix.

Example:

feature-login
bugfix-login-error

## 2. Make Changes

Make the required changes in your assigned branch.

## 3. Commit Changes

Use clear and meaningful commit messages.

Example:

Add login feature

## 4. Push Changes

Push the branch to the GitHub repository.

## 5. Create a Pull Request

Create a pull request from the working branch to the main branch.

## 6. Code Review

Another contributor reviews the changes and provides feedback.

## 7. Merge

After successful review, the pull request can be merged into the main branch.

## 8. Issue Reporting

Use GitHub Issues to report bugs, suggest improvements, or discuss tasks.
