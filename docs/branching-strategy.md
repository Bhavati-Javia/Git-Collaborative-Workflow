# Branching Strategy

The project uses separate branches for different development tasks.

## Main Branch

The main branch contains the stable version of the project.

## Feature Branch

Feature branches are created when developing new features.

Example:

feature-login

## Bug Fix Branch

Bug fix branches are created to solve reported problems.

Example:

bugfix-login-error

## Branch Workflow

main → feature/bugfix branch → Pull Request → Code Review → main
